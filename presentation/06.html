Phase 2 — First Attempt

Starting Phase 2: the wrong output format

Phase 2 begins from temp_merged_phase1. The first question: how should the model output its answer? The first answer was wrong.

Attempt: JSON extraction

The natural NLP framing — have the model extract entities as a structured JSON object with spans and types.

{
  "entities": [
    {"text": "Mario Rossi", "type": "NOME"},
    {"text": "67", "type": "ETÀ"}
  ]
}

Result: macro-F1 ≈ 0.13

✗

JSON parsing broke on malformed output

✗

Span offsets were inconsistent

The fix: inline redaction

Output the full note text with PII replaced in place. No parsing, no JSON, no spans — the output IS the answer.

Il paziente [NOME], di [ETÀ] anni,
è stato ricoverato presso
[LUOGO/INDIRIZZO] il [DATA]...

Inline redaction removes parsing and matches the evaluation metric.

Key insight: when the task is redaction, make the output a redacted document — not a metadata extraction. The model is a text processor, not a JSON emitter.
