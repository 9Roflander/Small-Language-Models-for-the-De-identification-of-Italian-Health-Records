Phase 1 — Motivation

The base model isn't ready for Italian clinical text

meta-llama/Llama-3.2-3B is trained predominantly on English web text. Italian clinical prose is a completely different register.

What makes Italian clinical prose hard

1

Dense medical terminology

Latin abbreviations, diagnostic codes, specialty jargon

2

Passive constructions

Heavy use of impersonal forms: si riscontra, viene effettuato

3

Variable date/age formats

Dozens of ways to write the same date or age in clinical notes

The two-problems-at-once trap

Skipping Phase 1 forces the model to learn two things at once:

🇮🇹

Learn Italian clinical register

+
🏷️

Learn the redaction task

Phase 1 decouples these. Domain knowledge first, then task learning.

The solution: continual pre-training

Pre-train on unlabeled Italian clinical text so the model learns the domain before redaction training.
